Inverted Search Engine

Project Overview
The Inverted Search Engine is a C-based application that creates an inverted index to search for words across multiple text files efficiently. It uses Hash Tables and Linked Lists to organize and retrieve information.

Features
- Create an inverted database from multiple text files.
- Search for a specific word.
- Display the complete database.
- Track word occurrences in different files.
- Save the database into a backup file.
- Update the existing database with new files.
- Validate input files and prevent duplicate entries.

Technologies Used
- C Programming
- Data Structures
- Hash Tables
- Singly Linked Lists
- File Handling
- Pointers
- Dynamic Memory Allocation
- GCC Compiler




 Learning Outcomes
- Practical implementation of data structures.
- Understanding hash tables and linked lists.
- Efficient file handling and searching.
- Dynamic memory allocation in C.

 Conclusion
This project demonstrates how an inverted indexing system works and provides an understanding of the fundamental concepts used in search engines and information retrieval systems.
